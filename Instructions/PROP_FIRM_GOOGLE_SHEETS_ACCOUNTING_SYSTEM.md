## 🏗️ GOOGLE SHEETS ARCHITECTURE

### **Sheet 1: COMPANY INFO**
```
Cell A1: PROP TRADING FIRM ACCOUNTING SYSTEM
Cell A2: [Company Name]
Cell A3: [Industry: Prop Trading/CFD]
Cell A4: Fiscal Year End: [Date]
Cell A5: Currency: USD
Cell A6: # of Cost Centers: 11
Cell A7: System Type: Multi-sheet integrated accounting
```

### **Sheet 2: COST CENTERS**
```
Columns:
  A | CC Code (CC01, CC02, etc.)
  B | Department Name
  C | Department Head
  D | Type (Revenue/Support)
  E | Monthly Budget
  F | YTD Actual
  G | YTD Variance
  H | Allocation Method (for support CCs)
```

### **Sheet 3: CHART OF ACCOUNTS**
```
Columns:
  A | Account Code (1010, 4020, etc.)
  B | Account Type (Asset, Liability, Revenue, Expense)
  C | Account Name
  D | CC Eligible? (Y/N)
  E | Normal Balance (Debit/Credit)
  F | Category
```

### **Sheet 4: JOURNAL ENTRIES (INPUT SHEET)**
```
Columns:
  A | Entry ID (JE001, JE002, etc.)
  B | Date
  C | Cost Center (CC01, CC02, CORP, etc.)
  D | Account Code
  E | Account Name
  F | Debit Amount ($)
  G | Credit Amount ($)
  H | Description
  I | Reference/Source
```

### **Sheet 5: GENERAL LEDGER (AUTO-CALCULATED)**
```
Columns:
  A | Account Code
  B | Account Name
  C | Cost Center
  D | Debit This Period
  E | Credit This Period
  F | Running Balance
  G | CC Total

Formulas:
  D = SUMIFS(JE!$F:$F, JE!$D:$D, $A2, JE!$C:$C, $C2)
  E = SUMIFS(JE!$G:$G, JE!$D:$D, $A2, JE!$C:$C, $C2)
```

### **Sheet 6: COST CENTER LEDGER**
```
Columns:
  A | Cost Center
  B | Period Revenue
  C | Period Expenses
  D | Period Contribution
  E | YTD Revenue
  F | YTD Expenses
  G | YTD Contribution
  H | Margin %

Formulas:
  Revenue = SUMIFS(GL!D:D, GL!C:C, A2, CoA!D:D, "Y") [only 40xx]
  Expenses = SUMIFS(GL!E:E, GL!C:C, A2, CoA!D:D, "Y") [only 50xx]
```

### **Sheet 7: TRIAL BALANCE (AUTO)**
```
Columns:
  A | Account Code
  B | Account Name
  C | Debit Total ($)
  D | Credit Total ($)
  E | Balance ($)

Formulas:
  C = SUMIF(GL!$A:$A, A2, GL!$D:$D)
  D = SUMIF(GL!$A:$A, A2, GL!$E:$E)
  E = C2 - D2
```

### **Sheet 8: INCOME STATEMENT (AUTO)**
```
Sections:
  1. REVENUES
     4010 - Challenge Fees 1-Step
     4020 - Challenge Fees 2-Step
     4030 - Instant Funding Fees
     4040 - Profit Share Commission
     4050 - Spread Markup
     4060 - Per-Trade Commission
     4070 - Platform Subscriptions
     4080-4120 - Other Revenue
     Total Revenue = SUM(all 40xx credits)
  
  2. EXPENSES
     5010-5060 - Trader Payouts & Platform
     5100-5130 - Salaries & Compensation
     5200-5220 - Tech & Operations
     5300-5320 - Marketing & Community
     5400-5500 - Professional & Insurance
     5600-5900 - Admin & Depreciation
     Total Expenses = SUM(all 50xx debits)
  
  3. PROFIT
     Operating Income = Revenue - Expenses
     Interest Expense (6000)
     Income Tax Expense (6100)
     Net Income = Operating - Interest - Tax
```

### **Sheet 9: BALANCE SHEET (AUTO)**
```
ASSETS:
  Current Assets:
    1010 - Cash
    1020 - Receivables
    1030 - Commission Receivable
    1040 - Subscriptions Receivable
    Total Current = SUM
  
  Non-Current Assets:
    1100 - Platform Assets
    1110 - Depreciation
    1200 - Goodwill
    1300 - Intangibles
    Total Non-Current = SUM
  
  TOTAL ASSETS = Current + Non-Current

LIABILITIES:
  Current Liabilities:
    2010 - Trader Payouts Due
    2020 - Deferred Revenue
    2030 - Accrued Expenses
    2040 - Platform Payables
    2050 - Broker Payables
    Total Current = SUM
  
  Non-Current:
    2100 - Short-term Debt
    2200 - Long-term Debt
    Total Non-Current = SUM
  
  TOTAL LIABILITIES = Current + Non-Current

EQUITY:
  3010 - Common Stock
  3020 - Paid-in Capital
  3100 - Retained Earnings
  + Net Income (from IS)
  TOTAL EQUITY = SUM

Check: Assets = Liabilities + Equity
```

### **Sheet 10: CASH FLOW STATEMENT (AUTO)**
```
OPERATING ACTIVITIES:
  Net Income (from IS)
  + Depreciation
  - Increase in Receivables
  + Increase in Payables
  = Cash from Operations

INVESTING ACTIVITIES:
  - Platform Investment (1100)
  - Acquisition Spending
  = Cash from Investing

FINANCING ACTIVITIES:
  + Loan Proceeds
  - Debt Repayment
  + Stock Issuance
  = Cash from Financing

NET CHANGE IN CASH = Op + Inv + Fin
Beginning Cash + Change = Ending Cash
```

## 🔧 SETUP INSTRUCTIONS FOR GOOGLE SHEETS

### **Step 1: Create Spreadsheet**
1. Go to Google Sheets (sheets.google.com)
2. Click "New" → "Blank Spreadsheet"
3. Name it: "BROCTAGON_Accounting_System" (or your company name)
4. Rename Sheet1 to "Company Info"

### **Step 2: Create All 14 Sheets**
```
Right-click sheet tab → Add sheet
Repeat for each:
- Company Info
- Cost Centers
- Chart of Accounts
- Journal Entries
- General Ledger
- Cost Center Ledger
- Trial Balance
- Income Statement
- Balance Sheet
- Cash Flow Statement
- Revenue Analysis
- Expense Analysis
- Cost Allocation
- Dashboards
```

### **Step 3: Populate Chart of Accounts**
Copy the account list into Sheet 3 (Chart of Accounts)

### **Step 4: Create Input Template**
In Journal Entries sheet, create headers and format for data entry:
```
A1: Entry ID
B1: Date
C1: Cost Center
D1: Account Code
E1: Account Name
F1: Debit ($)
G1: Credit ($)
H1: Description
I1: Reference
```

### **Step 5: Build Formulas**
Use SUMIFS() to auto-calculate GL from Journal Entries:
```
Example Formula in GL Sheet:
=SUMIFS(JournalEntries!$F:$F, 
        JournalEntries!$D:$D, A2,
        JournalEntries!$C:$C, C2)
```

### **Step 6: Create Financial Statements**
Build IS, BS, CF using references to GL and TB

### **Step 7: Share & Protect**
- Share with team members
- Protect GL, TB, IS, BS sheets (formulas)
- Leave Journal Entries unlocked for data entry
